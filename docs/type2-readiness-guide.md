# Type 2 readiness notes

## Type 1 and Type 2
A SOC 2 Type 1 report covers whether controls are suitably designed at a point in time. A Type 2 report also covers whether they operated effectively over a period, often 3 to 12 months. One good example isn't enough for Type 2, and a missed month can't be recreated later.

## ISO 27001 and SOC 2
| | ISO/IEC 27001:2022 | SOC 2 |
|---|---|---|
| Outcome | Certification of a management system | CPA attestation report |
| Criteria | Clauses 4 to 10, plus Annex A controls | AICPA Trust Services Criteria |
| Scope choice | Statement of Applicability | Security is required; Availability, Confidentiality, Processing Integrity and Privacy are optional |
| Cycle | Three-year certificate with surveillance audits | Report for each period, usually renewed annually |

## How this project treats findings
- **Gap:** evidence is missing for a required period or sampled item.
- **Exception:** evidence exists, but shows the control didn't work as intended.
- **Ready:** every required item has passing evidence. This isn't an audit opinion.

## Limits
- The control mappings are my own working mapping. Check them against the official standards and the mapping published by AICPA.
- Sample sizes are illustrative, because the auditor determines the actual testing.
- This tool checks records. It doesn't judge whether the evidence itself is adequate.
